## WallpaperRotater
Rotate yo wallpapers on windows!

# Currently only works for windows, will see if I can get a linux/mac release! (probably not idk)

Exactly what it sounds like: I have lots of different cool pieces of art, and I want to rotate between them for my wallpapers :p

Download the .exe from releases and run it to use the program.

NOTE: The current version is only able to the following files for the background: .jpg, .jpeg, .png, .bmp, .gif, .tiff, .tif, .dib
